# Example brief: a smoke test for Steward

This is an example brief. It checks that a managed run starts, writes its checkpoint and ends.

1. Create a file named `steward-hello.txt` in the current directory containing the line
   `hello from a managed run`.
2. Update your checkpoint with what you did and how to verify it (`cat steward-hello.txt`).
3. Finish with a one-line report.
