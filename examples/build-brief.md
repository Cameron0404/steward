# Example brief: add a feature to a small project

**Repo: ~/code/example-project**

This is an example of a longer brief. Replace the repo path and the task with your own.

Goal: add a `--json` flag to the project's `report` command so it prints its output as JSON.

1. Read the README and the `report` command's source before changing anything.
2. Add the flag, with a test that runs `report --json` and parses the output.
3. Run the whole test suite. It must pass before you finish.
4. Commit on a new branch named `feature/report-json`. Do not push.

Your report: what changed, the test command and its result, and anything left undone.
